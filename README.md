# BUMAKO — Master Komoditas SPDT NTP 2026

Web pencarian cepat dan navigasi bertingkat (Daftar Isi) kode Master Komoditas untuk Survei Pertanian (SPDT/NTP) 2026 Badan Pusat Statistik (BPS).

🔗 **[Buka BUMAKO (GitHub Pages)](https://ridsonap.github.io/bumako)**

## Fitur Utama

- 🔍 **Pencarian Cepat Selalu di Depan**: Cari nama komoditas, kode 7 digit, kelompok, atau subkelompok secara instan.
- 📖 **Daftar Isi Interaktif (Table of Contents)**: Navigasi bertingkat ala buku master (*Konsumsi & 7 Subsektor Pertanian* ➔ *Kelompok* ➔ *Subkelompok*) berbentuk collapsible card.
- 🏷️ **Filter Tipe Lengkap**: Filter instan berdasarkan *Konsumsi*, *Produksi*, dan *Biaya Produksi*.
- 📋 **1-Click Copy Code**: Klik badge kode untuk langsung menyalin ke clipboard disertai toast notifikasi.
- 🌓 **Tema Terang & Gelap**: Default tema terang (*clean light*), tersimpan otomatis di browser.
- 📱 **Mobile Card Layout**: Tampilan tabel optimal di desktop dan kartu informasi praktis di smartphone lapangan.
- ⚡ **100% Client-Side & Offline-Ready**: Berjalan tanpa server/backend dengan total **3.034 komoditas**.
